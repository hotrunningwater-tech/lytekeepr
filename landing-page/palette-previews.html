LyteKeepr color directions

Five palette-only variants using the same LyteKeepr landing-page structure and copy. A warm amber stays the signature accent throughout — a small "keeper's light" motif — while the base atmosphere changes in each version. None use red/white flag tones or government-portal styling, per the brand spec.

Option 1

Harbor Slate

Cool navy and steel blue. Calm, structured, and the most "official-adjacent" without tipping into government styling — reads as serious record-keeping software.
